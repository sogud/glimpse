## 一、产品概述

### 1.1 产品定位

| 属性 | 描述 |
|------|------|
| **产品名称** | PhotoSwipeCleaner (相册整理大师) |
| **核心定位** | 极简高效的 iPhone 相册整理工具 |
| **目标用户** | 手机照片超过 1000 张、相册混乱的 iOS 用户 |
| **价值主张** | 像刷短视频一样快速整理千张照片，5 分钟释放数 GB 空间 |
| **差异化** | Tinder 式交互 + 智能分类 + 游戏化体验 |

### 1.2 用户痛点

- 📸 **照片爆炸**: iPhone 用户平均存储 3000+ 张照片，90% 从未回看
- 🔍 **查找困难**: 重要照片淹没在截图、重复照片、模糊照片中
- ⏱️ **整理耗时**: 原生相册整理效率低，批量操作繁琐
- 💾 **空间焦虑**: 存储空间不足，但不敢随意删除怕误删重要照片

### 1.3 核心体验

```
打开 App → 选择分类 → 滑动整理 → 查看成果
   ↓           ↓           ↓           ↓
  2秒        3秒        5分钟      即时反馈
```

## 三、功能详细设计

### 3.1 核心整理增强

#### 3.1.1 智能分类入口

**功能描述**: 首页顶部横向滚动分类卡片，快速进入特定照片集合

**分类列表**:

| 分类 | 图标 | 描述 |
|------|------|------|
| 全部照片 | photo.stack | 所有照片按时间排序 |
| 截图 | crop | 自动识别的屏幕截图 |
| 相似照片 | square.grid.2x2 | 拍摄时间/内容相近的照片 |
| 重复照片 | doc.on.doc | 完全重复的照片 |
| 大文件 | externaldrive | 大于 10MB 的照片/视频 |
| 模糊照片 | eye.slash | 对焦失败或手抖的照片 |
| 最近添加 | clock.arrow.circlepath | 最近 7 天新增 |
| 按年份 | calendar | 按年份筛选 |
| 未整理 | questionmark.folder | 从未被整理过的照片 |

**UI 设计**:
- 横向滚动卡片列表
- 每个卡片显示: 图标 + 类别名称 + 照片数量
- 选中状态高亮显示

#### 3.1.2 批量选择模式

**触发方式**: 长按照片进入批量模式

**功能**:
- 点击多选照片
- 全选/取消全选
- 底部操作栏: 删除 / 移动到相册 / 收藏 / 导出

#### 3.1.3 照片对比模式

**使用场景**: 相似照片二选一

**界面**:
- 左右分屏对比
- 显示相似度百分比
- 快速选择保留/删除

### 3.2 智能助手 (AI 功能)

#### 3.2.1 相似照片检测

**算法策略**:
1. **时间窗口优化**: 同 5 分钟内拍摄的照片优先比对
2. **特征提取**: 使用 Vision 框架提取图像特征向量
3. **相似度阈值**: 默认 0.85，可调节

```swift
// 伪代码
func findSimilarPhotos(from assets: [PHAsset]) async -> [[PHAsset]] {
    // 1. 按时间分组
    let timeGroups = groupByTimeWindow(assets, window: 5min)
    
    // 2. 每组内特征提取
    for group in timeGroups {
        let features = await extractFeatures(group)
        
        // 3. 相似度聚类
        let clusters = clusterBySimilarity(features, threshold: 0.85)
    }
}
```

#### 3.2.2 截图识别

**识别规则**:
1. 文件名包含 "Screenshot" 或 "截屏"
2. 尺寸比例符合常见设备屏幕比例
3. 图片顶部包含状态栏特征像素

#### 3.2.3 大文件扫描

- 扫描 > 10MB 的照片和视频
- 按文件大小排序
- 支持视频预览

### 3.3 数据统计与游戏化

#### 3.3.1 统计仪表盘

**核心指标**:

| 指标 | 说明 |
|------|------|
| 总释放空间 | 累计释放的存储空间 (GB) |
| 整理照片数 | 累计整理的照片数量 |

**可视化**:
- 顶部大数字展示

- 折线图: 近 30 天整理趋势

## 四、用户体验设计

### 4.1 新手引导流程 (Onboarding)

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   欢迎页     │ →  │  手势教程    │ →  │  权限申请    │
│  品牌介绍    │    │  交互教学    │    │  相册权限    │
└─────────────┘    └─────────────┘    └─────────────┘
                                             ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  开始整理    │ ←  │  智能分析    │ ←  │  初始化扫描  │
│  快速获胜    │    │  展示发现    │    │  分析相册    │
└─────────────┘    └─────────────┘    └─────────────┘
```

**步骤详解**:

1. **欢迎页**: 品牌 slogan + 核心动效预览
2. **手势教程**: 必须实际操作一次才能继续
   - 左滑删除 (红色)
   - 右滑保留 (绿色)
   - 上滑归档 (蓝色)
   - 下滑跳过 (灰色)
3. **权限申请**: 解释为何需要权限
4. **智能分析**: 显示发现的可优化照片统计
5. **开始整理**: 直接进入"截图"分类快速获胜

### 4.2 操作反馈系统

| 操作 | 视觉 | 触觉 | 声音 |
|------|------|------|------|
| 左滑删除 | 红色遮罩 + 垃圾桶图标 | Heavy impact | 删除音 |
| 右滑保留 | 绿色遮罩 + 对勾图标 | Light impact | 确认音 |
| 上滑归档 | 蓝色遮罩 + 文件夹图标 | Medium impact | 滑动音 |
| 完成一组 | 撒花动画 + 统计弹窗 | Success | 胜利音 |

### 4.3 空状态设计

| 场景 | 插画 | 标题 | 操作 |
|------|------|------|------|
| 未授权 | 🔒 | 需要相册权限 | 去设置开启 |
| 全部完成 | 🎉 | 太棒了！全部整理完成 | 查看统计 |
| 分类为空 | 📂 | 该分类暂无照片 | 切换分类 |
| 加载失败 | ⚠️ | 加载失败 | 重试 |

### 5.2 技术选型

| 功能 | 方案 | 理由 |
|------|------|------|
| 图像相似度 | Vision 框架 | 原生，隐私安全 |
| 动画效果 | SwiftUI + Lottie | 原生优先，复杂动效用 Lottie |
| 数据存储 | UserDefaults + Core Data | 简单数据 UD，大量数据 CD |
| 图表 | Swift Charts | iOS 16+ 原生 |
| 声音 | AVFoundation | 系统音效 + 自定义 |

### 5.3 性能优化

- **图片加载**: 使用 `PHImageManager` + 合适的目标尺寸
- **相似度计算**: 后台线程 + 进度回调
- **内存管理**: 照片列表懒加载，及时释放
- **存储优化**: 统计指标本地缓存，定期上报
