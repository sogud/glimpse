# PhotoSwipeCleaner UI 布局设计 V2

> 基于 PRD 重新设计，Tinder 风格极简交互

---

## 核心设计理念

1. **全屏卡片**: 照片占满屏幕，无干扰
2. **手势优先**: 滑动是主要操作，按钮只是辅助
3. **零思考**: 用户不用看说明书就知道怎么用
4. **即时反馈**: 每个操作都有视觉+触觉反馈

---

## 1. 主界面

### 1.1 照片卡片

**尺寸**: 占满除底部提示外的全部空间
**边距**: 左右 16pt，上下无（延伸到安全区）
**圆角**: 20pt

**信息层**:
```
┌────────────────────────┐
│ ┌────┐                 │
│ │1/50│  2024.01.15     │  ← 左上角计数，右上角日期
│ └────┘                 │
│                        │
│                        │
│                        │
│        [照片内容]       │
│                        │
│                        │
│                        │
│          稍后处理 ↑     │  ← 上滑提示（滑动时出现）
│  删除 ←  → 归档        │  ← 左右滑提示（滑动时出现）
└────────────────────────┘
```

**滑动时的方向标签**:
- 左滑: 卡片上出现红色 "删除" 标签，随滑动距离渐显
- 右滑: 卡片上出现蓝色 "归档" 标签
- 上滑: 卡片上出现灰色 "稍后" 标签

### 1.2 底部静态提示

**样式**: 纯文字，无背景，半透明
**位置**: 底部安全区上方 20pt
**内容**:
```
← 删除        → 归档
      ↑ 稍后
```

**实现**:
```swift
VStack(spacing: 8) {
    Label("稍后", systemImage: "arrow.up")
        .font(.caption)
        .foregroundColor(.secondary)

    HStack {
        Label("删除", systemImage: "arrow.left")
            .foregroundColor(.swipeDelete)
        Spacer()
        Label("归档", systemImage: "arrow.right")
            .foregroundColor(.swipeArchive)
    }
    .font(.subheadline.weight(.medium))
}
.padding(.horizontal, 60)
.padding(.bottom, 20)
```

**设计理由**:
- 不抢照片的视觉焦点
- 始终可见，提醒用户可滑动
- 无需按钮，避免与手势功能重复

## 2. 操作反馈

### 2.1 滑动中（未达到阈值）

- 卡片跟随手指移动
- 背景渐变暗示方向颜色（红/蓝/灰）
- 方向标签渐显（0% -> 50% 透明度）

### 2.2 达到阈值（即将触发）

- 方向标签 100% 显示
- 卡片缩放至 0.95（给用户确认感）
- 触觉反馈（轻点）

### 2.3 操作完成

- 卡片滑出屏幕
- 下一张卡片放大进入（从 0.9 -> 1.0）
- 显示操作确认 Toast（可选）

## 3. 撤销机制

### 方案 A: 下滑撤销（PRD 定义）

**交互**:
- 在任意位置下滑
- 撤销上一个操作
- 恢复上一张照片

**视觉**:
- 下滑时出现 "撤销" 标签（黄色）
- 卡片从下方滑入（反向动画）

### 方案 B: 底部 SnackBar（推荐）

**触发**: 删除/归档后显示 3 秒

```
┌─────────────────────────────┐
│  已删除 1 张照片    [撤销]   │
└─────────────────────────────┘
```

**优势**:
- 不干扰滑动手势
- 明确告知用户操作结果
- 给后悔时间，但不用时可以忽略

## 4. 相册选择

### 触发方式

**方案 A: 右滑直接弹出**（当前实现）
- 右滑超过阈值 → 弹出相册选择器
- 选择后完成移动

**方案 B: 右滑两步确认**
- 右滑 → 卡片暂时固定，显示 "选择相册"
- 点击展开选择器
- 适合有默认相册的用户

## 11. 关键代码片段

### 卡片手势检测

```swift
DragGesture()
    .onChanged { value in
        let horizontal = value.translation.width
        let vertical = value.translation.height

        // 优先判断主要方向
        if abs(horizontal) > abs(vertical) {
            // 水平滑动：删除 / 归档
            direction = horizontal < 0 ? .delete : .archive
        } else {
            // 垂直滑动：稍后 / 撤销
            direction = vertical < 0 ? .later : .undo
        }

        // 更新卡片位置和背景
        updateCardState(translation: value.translation, direction: direction)
    }
    .onEnded { value in
        if shouldTriggerAction(translation: value.translation) {
            executeAction(direction)
        } else {
            resetCard() // 弹性回弹
        }
    }
```

### 方向标签视图

```swift
@ViewBuilder
private func directionLabel(for direction: SwipeDirection) -> some View {
    if direction != .none {
        Text(direction.label)
            .font(.title2.bold())
            .foregroundColor(.white)
            .padding(.horizontal, 24)
            .padding(.vertical, 12)
            .background(
                Capsule()
                    .fill(direction.color)
            )
            .opacity(calculateOpacity())
            .scaleEffect(calculateScale())
    }
}
```
